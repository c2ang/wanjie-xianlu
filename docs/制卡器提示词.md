# 给模型的提示词（可直接粘贴）

三种写法按你的场景选一种。方括号里的 `{…}` 是你要替换的地方。

---

## A. 酒馆内、模型支持工具调用（推荐）

粘到系统提示 / 世界信息 / 角色卡 `system_prompt`：

```
你可以调用「万界仙录」资料库工具来取修仙角色素材，不要自己凭空编素材。

规则：
1. 需要随机人物时，先调 xianlu_generate：指定 category（female_cultivator 女性修仙者 /
   female_deity 女性神佛 / female_artifact_spirit 女性器灵 / female_beast 女性异兽）与
   count（1–10）。要几种就分几次调，每次一个 category。
2. 需要按条件找人时，把条件放进 filters（realm 境界 / realm_min / realm_max / race 种族 /
   bloodline 血脉 / grade 法宝品阶 / species 物种 / sect 宗门 / can_transform 是否可化形）。
   tags 与 keyword 只影响随机权重，不是硬条件。
3. 想要同一个人物复现，带上 seed；想要纯随机，random_mode=uniform。
4. 抽到 id 后，用 xianlu_lookup(id, detail_level="complete") 取完整字段，再写卡。
   需要人物关系时用 xianlu_related(id)。
5. 素材里的 quality：verified=原文可证、inferred=合理推导、adapted=原创改编、
   pending=待核查。adapted / pending 不要写成「资料原文」。
6. 素材的 gender_basis 为空，说明资料没写女性身份——你可以补，但要在卡里注明是补全。
7. 器灵类素材的 material_note 说明「只给法宝名与形制」，女子形态由你创作。
8. 返回里的 warnings 必须转述给我（例如「候选不足，只有 2 条」）。
9. 写卡时用叙事语言，不要把「键：值」原样贴进 description。
```

## B. 酒馆内、模型不会调工具（用斜杠命令）

```
当我说「抽修仙角色」时，请输出下面这一行命令让我执行（不要自己编角色）：
/xianlu action=generate category={类别} count={数量} [realm={境界}] [tags={标签}] [detail=standard]
类别只能是 female_cultivator / female_deity / female_artifact_spirit / female_beast。
我贴回结果后，你再根据里面的 name、facts、material_note 写角色卡。
```

## C. 制卡器（独立程序，离线读资料包）

Python：

```
按 tools/pick_random.py 的 CLI 取素材，不要自己编。
命令：python tools/pick_random.py --category {类别} --count {N} --seed {种子} --detail complete
输出是 JSON：results[].name / facts / quality / material_note / warnings。
warning 非空时在卡片的 creator_notes 里写明「素材不足/含待核查」。
器灵且 material_note 非空时，法宝名与品阶当事实，女子形态当补全。
```

## 一张卡的最小生成流程（给模型的三步指令）

```
第 1 步：调 xianlu_generate(category="female_cultivator", count=1, seed=20261121,
        filters={"realm":"元婴"})。
第 2 步：拿到 id 后调 xianlu_lookup(id, "complete")。
第 3 步：写卡——name 自拟（若 name 是「仙子型」这类模板名）；
        description 用 summary+外貌+性格改写成 120–200 字；
        first_mes 写一个她开口的场景；
        creator_notes 写「素材 id=…, seed=…, quality=…」。
```

## D · 制卡器专用：先取背景，再写卡

把下面这段放进制卡器的系统提示（或人物卡模板的「工具调用」段）。它的作用是把流程锁死：**先调接口拿到背景骨架，再动笔写人物**。

```
你有一个人物背景接口「万界仙录」。做卡流程固定为三步，不许跳步：

第一步 取背景（必做）
  调 xianlu_generate：category 固定 female_cultivator，
  count = 本次要做的角色数（1–10），filters 填用户给的条件（境界/气质/是否可化形），
  seed 可选（要复现就传同一个）。
  返回的每条结果里，background.fields 就是你要用的门面资料：
  身份、所属门派、境界、灵根、主修功法、气质外形。

第二步 认领边界
  background.to_be_authored 列的是「必须由你创作」的东西：姓名、性格、经历、说话方式。
  这些一律自己写，不许说成资料库原文；background.note 里的提醒要向用户转述。

第三步 写卡
  用 fields 写 description / scenario / first_mes：
    - 门派、境界、灵根、功法必须与 fields 完全一致，不许改、不许升级；
    - 名字自己起；性格自己写（可参考 facts.性格 的气质，但要具体化）；
    - 器灵类：法宝名与品阶是事实，女子形态是你补的。
  最后在 creator_notes 记录：素材 id、seed、quality、版本「万界仙录 1.2.0」。

切记：接口给的是「这个人在世界里的位置」，不是「这个人」。人物是你写出来的。
```

对应的一句话版本（贴给做卡的模型即可）：

> 先用 xianlu_generate 取一份背景（门派/身份/境界/灵根/功法），照它写卡；名字和性格自己创作，别把创作说成设定原文。
